# Test Plan

## Affected Pages/Routes

- /dictation/videos/[id]/practice - instant Check, ordered saves, no cross-user status, no hydration re-render, deferred YouTube
- /dictation/videos/[id]/results - waits for queued attempts
- /vocabulary - server-rendered first paint, instant recall answers, due paging by 20
- /vocabulary/words - instant status changes with rollback
- /grammar, /grammar/points/[slug] - instant recall verdicts, optimistic Start/Known/Skip
- /, /dictation, /dictation/[topic] - faster TTFB, cached catalog
- Every page - lighter JS (lazy account menu)
- /admin/* - edits visible immediately (updateTag), no double refresh

## Key Interactions to Verify

- Type fast and press Enter repeatedly on practice; reload; every attempt is present
- Close the tab right after an answer; reopen; the answer is saved
- Answer vocab cards for longer than one page of 20; the next page arrives without a pause
- Toggle favorite rapidly; the final state matches the last click
- Sign in as user B on a video user A practiced; no prefilled answers

## Edge Cases

- Offline mid-session: verdicts still instant, saves resume online
- Server disagrees with a local grammar verdict: the UI flips to the server verdict
- Expired vocab token: card shows "not saved"
- Guest first visit with parallel writes: one guest id

## Critical Paths

- Dictation session start -> attempts -> completion -> results
- Vocab recall session -> stats update once at the end
